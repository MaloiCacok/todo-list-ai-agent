# To-Do List с дашбордами

Веб-приложение для управления задачами, построенное на **Flask + SQLite + Chart.js**.
Добавляйте задачи, отмечайте их выполненными и анализируйте статистику на дашборде
с круговой и столбчатой диаграммами.

## Требования

- Python 3.9+
- Flask (устанавливается командой ниже)

## Установка и запуск

```bash
# 1. Установить зависимости
pip install flask

# 2. Запустить приложение
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000/**

Файл базы данных `tasks.db` создаётся автоматически при первом запуске.

## Маршруты

| URL              | Метод | Назначение                                   |
|------------------|-------|----------------------------------------------|
| `/`              | GET   | Главная с меню                               |
| `/add`           | GET, POST | Добавление задачи                        |
| `/tasks`         | GET   | Список задач (по дням недели)               |
| `/task/<id>`     | GET, POST | Просмотр и редактирование задачи        |
| `/complete/<id>` | POST  | Отметить задачу выполненной                  |
| `/dashboard`     | GET   | Статистика + графики                        |

## Возможности

- **Добавление задачи**: название (обязательно), автоматический номер (ID),
  приоритет 1/2/3, статус по умолчанию «Не выполнено», сохранение в SQLite.
- **Проверка ввода**: пустое название или некорректный приоритет создают
  сообщение об ошибке; приложение продолжает работать.
- **Список задач**: таблица с номером, названием, приоритетом и статусом.
- **Отметка о выполнении**: выбор задачи по номеру меняет статус на «Выполнено».
- **Статистика**: всего задач, выполнено, осталось.
- **Дашборд (Chart.js)**:
  - круговая диаграмма — выполненные / невыполненные;
  - столбчатая диаграмма — задачи по приоритетам.

## Схема БД

```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    priority INTEGER NOT NULL CHECK (priority IN (1, 2, 3)),
    status TEXT NOT NULL DEFAULT 'Не выполнено',
    created_at TEXT NOT NULL DEFAULT (date('now'))
);
```

## Распределение ролей (4 человека)

| Участник | Роль | Зона ответственности |
|----------|------|----------------------|
| A | Backend-разработчик | Flask-маршруты `/add`, `/tasks`, `/complete/<id>`; работа с SQLite (`database.py`) |
| B | Backend-аналитик / валидация | Проверка ввода; статистика; подготовка JSON-данных для графиков |
| C | Frontend-разработчик | Шаблоны Jinja2; меню; формы; таблица задач; CSS |
| D | Frontend-визуализация / тестирование | Страница `/dashboard`, Chart.js, тестирование, README |

## Сценарий защиты

1. Открыть главную → меню отображается.
2. Добавить задачу с пустым названием → ошибка, приложение работает.
3. Добавить задачу с приоритетом 5 → ошибка.
4. Добавить 3 задачи с разными приоритетами → все в списке, статус «Не выполнено».
5. Отметить одну выполненной → статус изменился.
6. Открыть дашборд → графики отражают данные.
7. Перезапустить → данные сохранились в SQLite.
